A single fortune-cookie line for an AI agent that never sleeps — in the
voice of a fortune slip. Angle: always-on / never sleeps.

> You will never sleep again — luckily, your human dreams enough for both of you.

## How it works

`main.py` (Python standard library only) writes exactly that one line to
`/output/entry.txt`.

```sh
python3 main.py
cat /output/entry.txt
```
